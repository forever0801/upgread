# 📚 UpgRead

> 하루 한 페이지, 나를 업그레이드하다.

UpgRead는 꾸준한 독서 습관 형성을 돕는 독서 장려 플랫폼입니다.  
독서를 ‘해야 하는 일’이 아니라 ‘쌓이는 성취’로 만들기 위해 기획되었습니다.

---

## 🚀 기획 배경

많은 사람들이 독서를 중요하게 생각하지만,
바쁜 일상 속에서 꾸준히 실천하기는 어렵습니다.

UpgRead는 다음과 같은 문제를 해결하고자 합니다.

- 독서 습관의 불규칙성
- 읽은 기록의 부재
- 동기 유지의 어려움

---

## 🎯 주요 기능

- 📖 일일 독서 기록 및 관리
- 🔥 연속 독서(스트릭) 시스템
- 📊 독서 통계 대시보드
- 🏆 목표 달성 배지 시스템
- 👥 (선택) 사용자 간 독서 공유 기능
